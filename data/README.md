# AppFinder data and APIs

Everything here is public and needs no key.

| What | URL |
|---|---|
| App catalog (CSV) | https://appfinder.tech/data/apps.csv |
| App catalog (JSON) | https://appfinder.tech/data/apps.json |
| Catalog statistics page | https://appfinder.tech/research |
| JSON API (OpenAPI) | https://appfinder.tech/api/v1/openapi.json |
| Markdown page of any app / category | `https://appfinder.tech/apps/<slug>.md`, `https://appfinder.tech/categories/<slug>.md` |
| Site summary for AI assistants | https://appfinder.tech/llms.txt |
| MCP server | https://appfinder.tech/api/mcp |

**License of the data downloads:** [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Credit "AppFinder (appfinder.tech)" and link to the page.

Ranking is never for sale: see https://appfinder.tech/trust/ranking.
